# 🔖 BookNook – A Small Online Library

BookNook is a simple online library platform where readers can explore books, add their own books, borrow books for a few days, and return them when finished. It provides an easy way to manage books and keep track of borrowing activities in one place.

## 🌐 Live Website

[Visit BookNook](https://book-nook-project-psi.vercel.app/)

# 🗝️ Key Features

- **Explore Books:** Browse all available books and discover new reads through a clean, responsive interface.

- **Latest Arrivals:** Explore the six newest books added to the library.

- **Add Books:** Logged-in users can add new books with images, descriptions, author names, and other details.

- **Book Management:** Users can view, edit, and delete the books they have added.

- **Borrow & Return:** Borrow books for a limited period and return them when finished.

- **Personal Borrowing History:** View borrowed books along with their borrowing and return dates.

- **Secure Authentication:** Register and log in using email and password or Google authentication.

- **Protected Routes:** Private pages and borrowing actions are accessible only to authenticated users.

- **Book Availability:** Available copies are updated automatically when books are borrowed or returned.

- **Duplicate Borrow Protection:** Users cannot borrow the same book more than once at the same time.

- **Responsive Design:** Enjoy a consistent browsing experience on mobile, tablet, and desktop devices.

- **Dark & Light Mode:** Switch between themes for a comfortable reading experience.
